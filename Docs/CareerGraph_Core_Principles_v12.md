# CareerGraph Core Principles v12

## Graph Language Philosophy

Human-first, AI-assisted.

User owns model, AI assists creation/explanation/validation.

AI proposes changes, never silent edits.

## Architecture

Human → Graph Language → Compiler → Runtime → .gmem
AI Agent generates/explains/validates, working upward.

## CareerGraph experience

First user may never see Graph Language.
Path: UI → MCP Interview → AI Agent → Graph Language generation → Compiler → Runtime → .cgraph

Developer can edit career.schema for customization.

## Continuity
Maintains layers, safety, versioning, pilot focus from v11 with human-first language philosophy.

# CareerGraph Core Principles v14

## Type System

Strict typing + runtime validation

Minimal types: String, Int, Float, Boolean, Date, Enum, Entity, Relation, List, Map, Optional

Compiler type checking → optimized schema, runtime validates live changes

## Rules vs Workflows

Rules: reactive, event → state change
Workflows: orchestration, sequence of actions

Separate engines

## Agent as Entity

Agent defined as Entity with permissions read/propose/execute
Execution via MCP to external AI model

## Human Context Layer

Fact Layer separate from Human Context Layer

Facts: Project, Technology
Context: migration difficulty, leadership growth, career moments

## Positioning

Graph Memory Core runtime for living knowledge models
Applications: CareerGraph, DocGraph, ProjectGraph, Agent Memory
